## سيناريوهات القبول

1. افتح صباحيًا أو مسائيًا دون التقيد بالساعة. حاول بدء شفت موظف آخر قبل إغلاق الأول: يجب منع التداخل. أغلق الأول وافتح التالي فورًا.
2. أنشئ طلب توصيل: تبويب التعبئة أولًا ومحدد افتراضيًا.
3. نفذ عمليات في شفتين. لوحة الإدارة تفتح على الحالي؛ اختر السابق وقارن المبيعات والكاش المتوقع. التحصيل المتأخر يتبع الشفت الذي قبضه، والمبيعات تتبع وقت التسليم الفعلي.
4. جهّز طلبًا ثم ألغِه من صفحة الموظف أو الإدارة، دون كتابة سبب. تأكد رجوع البضاعة للمحل أولًا. الحجز يتحرر والقوارير المجهزة تذهب للمراجعة، والمواد المستهلكة لا تُسترد.
5. سلّم طلبًا ثم افتح ملف العميل → مستحقات العميل → تصحيح طريقة الدفع لطلب مسلم. جرّب كوبونات إلى كاش ثم بالعكس. التأكيد يعني أن الدفع الموضح هو التحصيل الفعلي الكامل. الكوبونات تُعاد ويُسجل فرق النقد بالشفت المفتوح مع حفظ الحركات السابقة.
6. صفحة الأصناف والأسعار: لا يوجد تقرير بيانات التجربة؛ رابطه القديم يعيد إلى الآلة مثل بقية الصفحات غير الموجودة.
7. الآلة: جرّب `12 + 3 Enter`، الأرقام الجانبية، الفاصلة العشرية، Backspace وEscape، ثم أزرار اللمس/الفأرة. لم يكتمل فحص الهاتف الفعلي؛ الفحص الشخصي مطلوب قبل النشر.
8. عميل التجربة لديه ٤ قوارير أردنية ٢٠ لتر. اطلب ٣ تعبئات: القوارير الخاصة تُقترح تلقائيًا، لا تخصم قوارير المحل ولا تنشئ عهدة. جرّب طلبًا يجمع قوارير خاصة وقوارير المحل. العدد المملوك يُسجل من بيانات العميل تحت السعر الخاص، ويبقى ثابتًا بعد التسليم. لا توجد خطوة استلام أو إدخال الموجود بالمحل. يظهر تأكيد قوارير المحل فقط عند نقص العدد الخاص.
9. سلّم طلبًا مع «المبلغ باقي على العميل». افتح «مستحقات العملاء»: العميل والمبلغ يظهران، ويمكن فتح التسديد الجزئي من نفس الصفحة.
10. عميل التجربة لديه كوبونان. طلب ٣ تعبئات بسعر ٠٫٥٠٠: الافتراضي كوبونات، ويظهر كوبونان + ٠٫٥٠٠ كاش وتنبيه واضح قرب التأكيد. بدّل الباقي لكليك، وجرّب تغيير كامل الدفع لكاش. الأصناف غير التعبئة تبقى ضمن المبلغ النقدي. تحقق أن التكرار لا يخصم مرتين.

## العزل والتشغيل

المشروع المستخدم `demo-alfanar-preview` فقط. Auth على `127.0.0.1:9099` وFirestore على `127.0.0.1:8080`. تشغيل `scripts/preview/start.mjs` يفرض هذه القيم ويلغي مسار الاعتماد الخارجي، والتطبيق يرفض وضع التجربة في production أو مع مشروع مختلف. لا يوجد تجاوز لصلاحيات الإنتاج؛ حسابات التجربة موجودة داخل المحاكي فقط.

من تيرمنالك داخل مجلد المشروع شغّل `npm run dev:preview`. هذا الأمر يشغّل محاكيات Firebase بمشروع `demo-alfanar-preview`، ويجهّز البيانات الوهمية ثم يشغّل الموقع. انتظر رسالة `Ready` واترك التيرمنال مفتوحًا أثناء التجربة. لا تستخدم `npm run dev` العادي لهذه التجربة.

يحتاج محاكي Firestore إلى Java 21 أو أحدث وأدوات Firebase CLI. مسارات الأدوات لهذا الجهاز مجهزة في `.preview-tools.local.json` المستثنى من Git. بيانات المحاكي مؤقتة ما لم تُصدّر عمدًا؛ لا تُستورد بيانات المحل.
